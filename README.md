# cordova-plugin-seer

cordova app 通用接口

## 安装

### 命令行安装

- npm

``` shell
cordova plugin add cordova-plugin-seer

cordova plugin rm cordova-plugin-seer
```

- git

``` shell
cordova plugin add https://github.com/tadazly/cordova-plugin-seer.git

cordova plugin rm cordova-plugin-seer
```

- 本地调试

```shell
cordova plugin add /path/to/cordova-plugin-seer \
  --link

cordova plugin rm cordova-plugin-seer
```
